# Charm AI portfolio demo

Open the inbox, select Avery, then edit, approve or discard the example reply. Under Schedule, choose Scan inbox to review the suggested consultation or Add date to create your own appointment. Reset demo restores the example. Every contact, message & booking starts as synthetic example data.

This demo preserves the inbox, scheduling UI & action-error handling from Charm AI. A tab-local adapter replaces production services. Changes survive refresh in the same tab. SMS delivery, calendar sync, payments, video, reputation checks, authentication, training, infrastructure & production operations are excluded. The date suggestion is deterministic. The demo requires no account, API keys, database or environment variables.

## Run locally

Use Node.js 22 or later. Run `npm ci`, then `npm run dev`. Open the local address printed by Next.js. Use `npm test`, `npm run lint`, `npm run typecheck` & `npm run build` for verification. Run `npm start` to serve a production build.
